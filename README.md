Galli_Agency

Консольное приложение для регистрации пользователей системы «Агентство недвижимости».  


Цель работы
Реализация модуля регистрации с хешированием паролей и подключением к БД через ADO.NET Entity Framework с соблюдением 3-й нормальной формы.

Технологии
-Язык:C# (.NET Framework 4.8)
-IDE:Microsoft Visual Studio 2022
-БД:MS SQL Server (Entity Framework Database First)
-Архитектура:Многоуровневая (Console App + Class Library)

Структура решения

| Проект | Назначение |
|--------|------------|
| `Galli_PR5` | Консольное приложение (точка входа, UI, логика регистрации) |
| `Galli_HashLibrary` | Библиотека классов для хеширования паролей (SHA256) |

Ключевые классы
-`HashGenerator` (`Galli_HashLibrary`) — публичный метод `GenerateSha256Hash()` для безопасного хранения паролей.
-`Helper` (`Galli_PR5.Models`) — вспомогательный класс для CRUD-операций с БД через контекст `AgencyEntities`.
-`Program`— реализует консольный интерфейс регистрации с проверкой уникальности логина.
